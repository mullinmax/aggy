Installing it

  1. Download the zip above and unzip it somewhere you'll keep it — Chrome loads it from that folder every time it starts, so the Downloads folder is a poor choice.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped folder.
  4. Click the Aggy icon in the toolbar and sign in. The instance address is already filled in; you just need your username and password.

Developer mode is how a self-hosted extension is installed — this one isn't in the Chrome Web Store, because it talks only to your instance.

What it does

  • Save this page. Aggy extracts the article and shows you the title, image, and excerpt before you commit. 👍 / 👎 save and vote in one click, which teaches your feed's ranking.
  • Follow this site. It works out the best way to read the page — its subreddit, its channel, a feed the page advertises, or a feed built from the page itself — and previews the items before adding anything.
  • Right-click and shortcuts. "Save to Aggy" on any page or link, Alt+Shift+S to save, and Alt+Shift+U to save with an upvote.
